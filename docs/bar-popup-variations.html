2What every variation shares

Only the body differs — the interaction contract is fixed:

· Opens on left-click of the bar segment; clicking the segment again, outside, or Esc closes it.
· Primary button is Start / Pause / Resume by state; Stop and Skip are secondary.
· Maximize (🗗 / Max button) opens the full Tomate window — replaces the old right-click.
· Top or left 2px border in the phase color: accent, green (short), magenta (long), yellow (ready).
· Data still comes from `tomate status --json` once a second — bar, popup and window always agree.
