2What changes in the bar

The bar segment keeps its look (ring + time + project); only its click behavior changes.

Before → after

Before: left-click anywhere on the segment toggles start/pause; right-click opens the Tomate window.
After: left-click opens this popup; right-click still opens the Tomate window directly. Inside the popup, Start/Pause is the big primary button, Stop sits beside it, and 🗗 maximizes to the full window. ⏭ skips to the next phase.

Why a popup

A single toggle on a ~80px bar segment is cheap to trigger and shows nothing about the session. The popup gives a confirmable target for start/stop, shows round, end time, note and today's progress — and the maximize button replaces the discoverability the old right-click had.

Layout rules

· Popup width 340px, anchored above the bar segment (centerEnd section), same margin as other Omarchy popups.
· Top border 2px in the phase color: accent = focus, green = short, magenta = long, yellow = ready.
· Ring center icon shows the state: 🍅 focus, ⏸ paused, ▶ ready, ☕ breaks.
· The note line and project are hidden when empty; the popup shrinks gracefully.
· Click outside the popup (or Esc) closes it, without touching the timer.

3State reference

Colors and controls per phase — use the switcher above to see each live.

· Focus running — accent blue ring draining, primary button reads Pause.
· Paused — dimmed ring with pause glyph, button reads Resume, “paused time doesn't count as work” footnote.
· Short / Long break — green / magenta ring, coffee glyph, note line hidden.
· Ready — yellow full ring with play glyph, button reads Start, shows which phase would start.
· Idle — bar shows just the tomato glyph; the popup offers Start focus with the current project.
